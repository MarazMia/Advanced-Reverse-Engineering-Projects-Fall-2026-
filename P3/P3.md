# P3 - ELF Structure-Theorem Primes

P3 extends P2. It starts at the ELF entry point, switches to `main` when the
entry code is a standard `__libc_start_main` startup sequence, discovers the
reachable basic blocks, and converts each block into the prime form required by
the Structure Theorem.

For a block ending in a conditional jump, the block is emitted as an
if-then-else prime. All other blocks are emitted as sequence primes that set
`L` to the known successor address. When the successor cannot be determined,
`L` is set to `0`.

Run from the P3 directory with exactly one ELF argument:

```bash
python3 ./main.py ./reverse
```

The provided `block-test.asm` can be assembled and linked into an ELF test
program and then passed to the same command. Actually, its already given to you, so 
just use the compiled file. Several aother testing also done (ls, true, custom test file).

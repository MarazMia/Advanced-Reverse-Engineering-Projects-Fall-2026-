# P2 - ELF Block Extractor

This program reads an ELF file and prints its basic blocks. It starts at the entry point, or at main if the entry point is the standard start code that calls __libc_start_main. From there it follows the jumps and calls it can see, finds the other basic blocks, and prints each one once in order of address with a blank line between blocks. It uses pyelftools to read the file and capstone to disassemble it.

From the repository root, activate the virtual environment if it is not already active:

```bash
source .venv/bin/activate
```

Run P1 with exactly one argument: the path to an ELF executable.

```bash
python P2/main.py ./P2/reverse
```

Replace `./P2/reverse` with the path to another target executable.


To run it from the P2 directory level, on /usr/bin/ls, put main.py and analyze_elf.py in the same folder and run:

```bash
python3 ./main.py /usr/bin/ls
```

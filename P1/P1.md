# P1 — ELF Disassembler

## Objective

Implement a Python disassembler for AMD64 ELF executables. The program uses **pyelftools** to read the ELF file and extract its `.text` section, then uses **Capstone** to decode and print instruction addresses, mnemonics, and operands.

## Dependencies

- Python 3.14.4 or newer
- Capstone
- pyelftools

Dependencies are installed from the repository root using `requirements.txt`. See the root `README.md` for environment setup.

## Usage

From the repository root, activate the virtual environment if it is not already active:

```bash
source .venv/bin/activate
```

Run P1 with exactly one argument: the path to an ELF executable.

```bash
python P1/main.py ./P1/reverse
```

Replace `./P1/reverse` with the path to another target executable.

The program validates the input, locates the `.text` section, and prints the disassembled instructions. Invalid files, missing paths, and missing `.text` sections should produce appropriate error messages.

## Verification

Compare the output against GNU `objdump`:

```bash
objdump -d -Mintel -j .text --no-show-raw-insn ./P1/reverse
```

The instruction addresses, mnemonics, and operands should match, although whitespace and formatting may differ.
